📱First Time Connecting a New Phone or Laptop?
  1. Confirm this device is connected to the Makerspace Wi-Fi (not mobile 5G/cellular data).
  2. Tap Trust Local Security Certificate ↗. When the warning appears, tap Advanced → Proceed to 192.168.12.108 (unsafe).
  3. Return to this tab and tap Test Connection above.

Note: If a device skips step 2, mobile Chrome blocks untrusted local SSL connections and reports ERR_TOO_MANY_RETRIES.
